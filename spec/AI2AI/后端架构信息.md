## 3. 模块说明

### 3.1 核心框架 (`internal/core/`)

#### 模块系统 (`module/`)
```go
// Module接口定义
type Module interface {
    Name() string                    // 模块名称
    Init(container *Container) error // 初始化依赖
    Routes(r RouterGroup)            // 注册路由
}

// Container 依赖容器
type Container struct {
    DB     *gorm.DB
    Config *Config
}

// Config 容器配置
type Config struct {
    JWTSecret     string
    JWTExpire     interface{} // time.Duration
    RedisAddr     string
    RedisPassword string
    RedisDB       int
}
```

#### 配置管理 (`config/`)
```yaml
# config.yaml 结构
server:
  port: 8080
  mode: debug

database:
  host: localhost
  port: 3306
  name: plm
  user: root
  password: ${DB_PASSWORD}
  max_open_conns: 100
  max_idle_conns: 10

redis:
  host: localhost
  port: 6380

storage:
  type: minio
  endpoint: localhost:9000
  access_key: ${MINIO_ACCESS_KEY}
  secret_key: ${MINIO_SECRET_KEY}

jwt:
  secret: ${JWT_SECRET}
  expire: 24h  # 一天

log:
  level: debug
  format: console
```
