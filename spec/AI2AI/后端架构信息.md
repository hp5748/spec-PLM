### 3.3 权限自动同步机制

**文件位置**: `internal/modules/user/seeder/permission.go`

**工作原理**:
- 后端启动时自动执行 `SyncPermissions()`
- 检查数据库中是否存在定义的权限，不存在则创建
- 新权限自动分配给 ADMIN 角色
- **不会删除或修改已有权限**

**添加新权限的步骤**:
1. 在 `seeder/permission.go` 的 `DefaultPermissions` 中添加新权限
2. 重启后端服务，权限自动同步到数据库
3. 前端路由中使用对应的权限码（如 `material:view`）

**现有权限列表**:
| 模块 | 权限码 | 说明 |
|------|--------|------|
| user | user:view, user:create, user:edit, user:delete | 用户管理 |
| role | role:view, role:manage | 角色管理 |
| material | material:view, material:create, material:edit, material:delete, material:release | 物料管理 |
| document | document:view, document:upload, document:edit, document:delete, document:download | 文档管理 |
| bom | bom:view, bom:create, bom:edit, bom:delete, bom:export | BOM管理 |
| workflow | workflow:view, workflow:initiate, workflow:approve | 流程管理 |
| admin | admin:all | 系统管理（全部权限） |
